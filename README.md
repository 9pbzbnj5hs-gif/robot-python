# Python 图片处理工具

第二次培训作业：使用 Python 实现图片信息读取和基本编辑，练习 Agent 辅助开发及 Git 分支、提交和合并。

## 开发计划

1. 在 main 初始化项目说明、依赖清单和 .gitignore。
2. 在 dev 实现图片信息读取。
3. 在 dev 实现缩放、裁剪及新文件保存。
4. 在 dev 补齐旋转、翻转、灰度、格式转换和错误处理。
5. 运行测试、完善使用说明，将 dev 合并到 main。

## 环境配置

需要 Python 3.10 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

本项目选择 Pillow 完成图片处理，运行和每个功能的使用示例将在开发完成后补齐。
